# 快手推荐流

## 已确认范围

在抖音下方、飞瓜上方添加快手推荐任务。复用抖音运行状态、统计、配置与历史组件；不修改整体视觉风格。采集入口为 https://www.kuaishou.com/new-reco 。

## 运行方式

- 抖音与快手独立保存设置、规则、草稿和运行进度，可同时采集；暂停、继续、停止及设置锁定仅作用于当前平台。复用组件与筛选实现，共用研究台连接和串行上传队列。今日已刷继续汇总所有平台，并保留平台筛选。
- 开始时复用或打开同窗口快手推荐页；继续时在后台恢复，原页关闭则后台新建，保留计数和去重记录。
- 从当前激活的视频卡读取作者、视频身份、标题、时长、点赞、评论、收藏、头像、封面和发布时间原文。预加载的相邻卡片不参与本次采集。
- 停留时间、视频数/时长目标、视频硬规则、账号规则与评分复用现有实现。配置在开始新一轮时固定。
- 视频通过初筛后后台打开作者主页，读取粉丝、简介及已加载作品后关闭。无法完整读取主页的观察记录标记人工确认；不把未加载字段当作零。未验证完整作品列表，不触发要求完整列表的低粉新号例外。
- 保存成功后点击当前卡片的下一条按钮，并验证视频身份变化。页面离开推荐流、加载超时、要求登录/验证、保存失败或切换失败时暂停。
- 定时启动、自动点赞/收藏/关注、不感兴趣操作目前仍仅用于抖音，快手页面隐藏这些控制项。

## 验证

页面选择器来自当前快手推荐页及作者主页的实际 HTML。使用本地保存的快照核对激活卡、视频身份和作者数据结构；官方图标来自网页声明的 favicon。

自动化覆盖：路由边界、当前卡唯一性、视频身份、复用筛选实现、缺失主页复核、重复视频、数量上限、暂停恢复、后台新建、过期消息拒绝、页面离开与持久化恢复。`pnpm check` 229 项测试、类型检查、构建和 dist 校验通过。

实际 Chrome 短测：使用本地模式与 3 条视频目标完成采集，产生粉丝超上限、需人工确认、视频过短三种判断；在 1 条后暂停，从其他网页继续，当前网页保持不变，最终达到 3/3 自动暂停。测试结果没有上传。后台作者页读取与自动关闭正常。自动连播的保留与避免重复切换另有内容脚本测试覆盖。

待验证：长时间持续运行、所有快手页面变体、快手数据的研究台端到端上传。

## 配置隔离与验证

快手配置保存在 `draKuaishouConfig`，抖音保留原配置。首次迁移优先继承快手已有运行配置，否则复制有效的原配置；迁移后分别保存。旧的共用草稿保留在抖音，避免把无效草稿扩散到快手。既有任务继续使用本轮配置。

切换平台时恢复各自表单，保存请求携带平台标识，过期平台响应不会覆盖当前表单。开始新任务会保存当前平台设置，即使另一平台正在运行。自动化已覆盖独立保存、无效草稿隔离、重启恢复、双平台运行与独立暂停、共享队列顺序和上传计数归属。

本轮隔离修复已通过自动化检查和构建，尚未在用户正在使用的 Chrome 中重新加载验证。此前实测遗留的本地测试模式、3 条目标及旧草稿仍需在对应平台设置中检查并恢复；代码迁移保留用户已有数据。
