# 多平台自动找号助手隐私政策（待发布者确认）

本稿依据扩展 V1.1.20 的客户端实现整理。发布前由运营方补充真实运营主体、联系渠道、服务端数据保留与删除规则，并核实数据用途。确认后的完整政策应发布到无需公司登录即可访问的 HTTPS 页面。

## 功能与数据用途

多平台自动找号助手帮助团队从抖音、快手、B 站、飞瓜和星图等支持的平台中发现和整理达人及视频，按照配置的规则记录观察结果，并向已授权的研究台同步。

## 处理的数据

扩展在相关采集功能运行时处理达人名称、主页地址、粉丝及互动指标、视频标识、文案、标签、时长、发布时间、头像和封面链接，以及任务页面地址、采集时间、停留和切换记录、筛选判断、互动结果与运行统计。具体字段取决于平台和页面可提供的信息。

规则设置、任务进度、观察记录、去重记录、上传队列、界面偏好与设备配对授权保存在浏览器本地。按网站隐藏悬浮入口时，扩展在本地保存对应的网站偏好。

用户启用调试采样时，扩展还会保存相关卡片的 DOM 片段与结构化样本，供本地检查、导出和清空。客户端对常见敏感字段进行过滤；导出文件仍应由用户在分享前检查。

## 上传与接收方

连接研究台并运行正式任务后，扩展向团队配置的研究台后端发送采集观察、任务统计与授权请求。当前客户端使用 Supabase 托管接口提供配对和数据接收，研究台页面使用公司域名。设备授权令牌用于验证上传权限。

抖音与快手的正式观察包括未命中规则的记录。飞瓜和星图采集观察自动进入研究台上传队列；网络失败时在本机保留并重试。本地测试模式仅作用于抖音、快手与 B 站的新任务，已有正式上传队列继续同步。

数据的业务使用方为研究台运营团队。公开前，运营方需在此补全基础设施处理方、人工访问范围、进一步处理和共享规则，并明确与 Chrome Web Store Limited Use 要求一致的数据使用承诺。

## 用户控制

用户可以调整采集规则、暂停或停止任务、关闭定时运行，导出本地完整观察，并单独清空调试采样。停用扩展会停止扩展运行；卸载扩展会移除其浏览器本地存储。已上传的云端数据需要通过研究台运营方处理删除请求。
