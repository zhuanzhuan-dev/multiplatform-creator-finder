多平台自动找号助手隐私政策

生效日期：2026年9月24日。发布者：Xinwy。联系邮箱：windxinweiy@gmail.com。

本政策适用于 Chrome 扩展“多平台自动找号助手”，说明其在达人研究、任务执行和研究台同步过程中如何处理数据。

功能及处理的数据

扩展根据用户配置，在抖音、快手、B 站、飞瓜和星图等支持的平台发现和整理达人及视频。运行采集任务时，处理页面可提供的达人名称、主页地址、公开资料、粉丝及互动指标、视频标识、文案、标签、时长、发布时间、头像和封面链接。任务记录还包括页面地址、采集时间、停留和切换记录、筛选判断、互动结果及运行统计。

浏览器本地保存规则设置、任务进度、观察记录、去重记录、待上传队列、界面偏好、设备标识及研究台配对授权凭据。配对凭据用于验证用户授权的同步请求。启用调试采样时，还会在本地保存相关内容卡片的 DOM 片段与结构化样本，供检查、导出和清空。

数据用途与同步

这些数据用于执行用户设置的达人筛选任务、展示结果、去重、恢复任务、重试上传、诊断任务问题，以及在已授权的研究台内开展达人研究。

连接研究台并运行正式任务后，扩展通过 HTTPS 向团队研究台后端发送采集观察、任务统计和授权请求。当前数据接收与设备配对接口使用 Supabase 托管服务，业务接收方为用户授权连接的研究台运营团队。抖音与快手的正式观察包含未命中规则的记录。飞瓜与星图的自动采集和随浏览采集观察自动进入上传队列；网络失败时在本机保留并重试。仍在本机且具备稳定平台身份的旧观察会在升级后排队补传。本地测试模式仅使抖音、快手与 B 站的新任务结果留在本机，已有正式上传队列继续同步。

数据使用限制

发布者将数据用于上述扩展功能及用户授权的达人研究，仅向实现这些用途所需的研究台及基础设施服务传输数据。数据不用于出售、广告定向、信用评估或贷款决策，也不用于与扩展单一用途无关的活动。数据的使用和转移遵守 Chrome 应用商店用户数据政策及 Limited Use 要求。

保留、控制和删除

本地数据用于持续任务、查询历史和同步，保留至扩展清理相应记录或用户移除扩展数据。用户可调整规则、暂停或停止任务、关闭定时运行、导出本地完整观察，以及单独清空调试采样。卸载扩展会移除该扩展的浏览器本地存储。

已同步到研究台的数据独立于浏览器本地副本保存，卸载扩展不会同步删除云端记录。用户可以向研究台管理员或本页联系邮箱提出访问、更正、删除及撤销授权请求，并注明涉及的设备或任务信息。云端数据的保留与删除由相应研究台运营方依据研究用途及适用义务处理；请求所需的身份核验应使用最少必要信息，请勿通过邮件发送密码、验证码或访问令牌。

安全与政策更新

研究台授权凭据用于访问控制，传输采用 HTTPS。用户应妥善管理浏览器和研究台账号，并在共享调试导出文件前检查其中的页面内容。本政策发生变更时，会在本页更新正文及生效日期。隐私问题请联系 windxinweiy@gmail.com。
