# 找号助手交互与统计口径

本说明对应 V1.0.18 本地测试版，涵盖暂停继续、独立同步、结果布局及统计口径。

## 侧栏结构

顶部保留版本、工作台入口与设置按钮，运行状态放在运行卡片内。首次使用展示“登录并连接研究台”，授权完成后收为一行连接状态；连接管理与外观主题放在设置中。

运行卡片负责开始、暂停、继续、停止及运行健康状态。暂停后可继续原轮次，保留任务 ID、累计数据、最近记录与目标；暂停时间不计入运行时长和单条剩余等待。继续与开始使用相同的推荐页查找、打开方式：原任务页仍可运行时直接在该页恢复；原页已转到精选、其他网站或关闭时，在侧栏所在窗口复用或新建推荐页并重新绑定本轮。保留用户正在浏览的其他页面，停止时仅关闭由插件创建的任务页。重新绑定页面后从该页当前卡片继续读取，不沿用旧卡片的等待步骤。达到目标后开始新一轮。“查看详情”展示待同步记录、本轮已同步、定时安排和异常信息。

“本轮结果”先展示符合条件、新发现账号、需人工确认，再展示本轮已刷及可展开的过程明细，下面直接展示最近 5 条记录。历史记录保存在扩展 IndexedDB `dra-decision-history`，跨轮次保留滚动 24 小时的数据，无 100 条上限。首页查询最近 5 条与总数，按钮为“查看近 24 小时记录（N）”；完整页面每页 50 条，按平台来源、轮次、结果和关键词筛选。停止本轮后保留统计和时长，只有开始新一轮时重置本轮统计。升级时原子迁入旧存储中仍在近 24 小时内的有效记录，确认提交后移除旧存储路径；之前已经丢弃的记录无法补回。

## 指标定义

| 指标 | 口径 |
| --- | --- |
| 今日已刷 | 按北京时间自然日统计已处理且有可识别标识的内容，同一内容当天只计一次，包含直播、图文、广告与其他跳过内容 |
| 本轮已刷 | 当前轮次进入首次处理的内容数，已有本地处理记录的内容直接跳过；开始新一轮时重置 |
| 符合条件 | 通过初筛的内容次数，包含重复发现与需要人工确认的候选 |
| 新发现账号 | 本轮首次加入本机账号索引的账号数 |
| 需人工确认 | 本轮新发现账号中需要人工确认的累计数量，与新发现账号有包含关系；工作台处理后不会回减 |
| 重复发现 | 通过初筛但已存在于本机账号索引的次数 |
| 本轮已同步 | 当前 runId 的记录收到服务端成功或重复确认的数量；补传旧轮次不增加当前轮次计数 |
| 跳过原因 | 直播、图文、广告、类型未确认和账号资料读取失败分别记录；广告与媒介类型重叠时归入广告，避免重复计数 |

今日累计保存在 `chrome.storage.local` 的 `draDailyStats` 中，保留最近 30 天的每日总数，以及当天用于去重的内容标识。跨轮次、重启侧栏和浏览器后保留，跨天从零显示。功能启用前的数据不进行推算补录。数据属于当前浏览器配置，不在多台电脑之间同步；卸载插件或清除扩展存储会清除。

## 内容与规则

根据当前卡片的可见结构标识、媒体元素和专用控件判断类型，排除作者侧栏及隐藏元素。视频描述中出现“直播中”“进入直播间”“广告”等词语不会直接决定类型。仅普通视频进入视频与账号筛选，直播（包括图文直播）、图文、广告和无法确认类型的内容记录原因并跳过，不打开账号资料面板。

上传记录的 `content_type` 为 `video`、`live`、`photo` 或 `unknown`；广告通过独立的 `is_ad` 标记，并同时保存在 `rpa_feedback` 中。跳过记录使用 `is_relevant: false` 与 `decision: skip`。已排队的旧记录保持其原始类型，不重写历史数据。

“视频与账号规则”包括数值条件、“想找的内容”和“不需要的内容”。关键词匹配可读取的视频描述、话题、昵称、简介及作品文字，属于文字匹配。正向类别未匹配但符合其他条件的账号仍作为候选交给人工确认；排除关键词优先。既有 `gameBlacklist` 持久化字段继续承载用户保存的排除词，界面使用通用名称“排除关键词”，适用于所有内容类别。

## 连接与测试

上传由独立的后台闹钟处理，翻页确认只等待本地持久化与排队，不等待网络请求。暂停、停止后已有队列继续同步，浏览器重启时重建上传任务；网络失败重试，有效授权恢复后继续同步。

正式运行前验证研究台授权，授权失效时展示重新登录入口；正式任务在断开连接或确认授权失效时暂停。本地测试入口收在设置中的“开发调试”，启用时显示持续提示，数据仅保存在本机。

通过现有 `pnpm check` 验证类型、单元测试、构建与扩展文件。浏览器回归脚本覆盖产品流程、设置、主题、数值输入、鼠标渐变、布局和后台运行。内容分类使用真实浏览器 DOM 测试样例；线上抖音结构变化与登录授权的生产端到端验收仍需使用真实账号验证。

## 悬浮入口与本地测试

V1.0.17 已发布。关闭侧栏后，抖音页面显示悬浮雷达入口；点击恢复侧栏，展开侧栏时隐藏。同一窗口的多个侧栏连接分别计数。悬浮位置保存在 `draLauncherPosition`，主题沿用 `draTheme`，支持拖动及键盘上下调整。工具栏显示运行状态角标。页面悬浮入口不扩展到其他网站。

V1.0.18 以 Git 标签 `v1.0.18` 标识本地测试版本，提供 ZIP 测试包，远程发布尚未执行。账号展示接口本地改动位于父仓库的 `pair-poll`、`ingest` 及共享 `account-profile`；姓名和邮箱由服务端根据已认证账号 ID 查询，仅用于展示。在线接口部署前显示已连接账号 ID，既有连接继续可用。

原始采样设置保存在 `draDebugSettings`，默认关闭。启用后自动采样运行中卡片，也可在抖音页面通过设置手动采样并标记视频、直播、图文或广告。自动样本标为尚未确认。原始数据保存在扩展自身 IndexedDB `dra-local-raw-samples`，最多 200 条、25 MiB，单条最多 1 MiB；超过总量时替换最早记录。

样本包含当前卡片 DOM（最多 250,000 字符）、原始属性、解析结果、版本、时间和能从卡片 React props 读取到且匹配内容 ID 的结构化候选。清除脚本、表单值、敏感属性与凭据字段；对深度、节点数和字符串长度设限，截断情况记录在样本中。采样数据不进入上传队列，可导出 JSON 和清空。页面未暴露对应结构化数据时保留 DOM，并注明未取得；未抓取网络响应，也不以模拟样本的数值定义线上类型规则。

## 历史记录来源与清理

每条历史记录保存 `sourcePlatform`（`douyin`、`kuaishou`、`feigua`、`xingtu` 或 `unknown`），界面显示对应中文名称。来源根据实际采集上下文写入；旧版本仅实现抖音采集，因此旧记录迁移标记为抖音。当前其他来源的筛选与数据字段已具备，采集入口仍只有抖音。原始样本使用同名字段，上传记录在 `rpa_feedback.source_platform` 中携带来源，不修改已有上传契约。

历史库使用时间与“来源 + 时间”索引。每次查询严格排除超过 24 小时的记录，每次写入及后台每 5 分钟清理到期数据。完整页面按游标分页，返回当前页数据和统计，不把全部记录放入页面内存；后续页固定查询上界避免新数据插入导致翻页重复。停止本轮、开始新轮次、页面刷新和 worker 重启均保留仍有效的历史。设置、账号与本轮统计继续保存在 `chrome.storage.local`，大体积原始采样使用单独的 IndexedDB 库和容量上限。
