# 抖音完整主页 IP 补采开关验收

关联：[FAI-808](https://linear.app/fxxkai/issue/FAI-808)。版本 1.1.28，已按用户授权纳入本地提交；尚未推送、加载到已安装扩展或发布。

## 用户决定与实现

IP 属地缺失允许继续采集。仅额外打开完整主页的补采步骤由用户选择，默认关闭。

在抖音「任务设置 → 运行设置 → IP 属地补采」增加「允许打开完整主页补采 IP 属地」。说明交代优先读取侧栏触发的接口响应，开启后可能临时打开、关闭主页标签而产生闪动；关闭时保持缺失并继续采集。暂停后可修改，开始或继续本轮时生效。快手与其他平台不显示此开关。

`allowProfileIpFallback` 默认 false，历史配置缺字段也为 false。侧栏收到身份匹配的 IP 响应时照常保存；未捕获到响应且开关关闭时返回空结果，继续现有采集流程。勾选后使用已有的临时后台主页读取与关闭逻辑。页面采集端和后台消息处理端同时遵守该设置，旧页面消息不能绕过关闭状态。没有新增 IP 必填或筛选拦截。

## 当前浏览器实测：侧栏与直接请求的区别

2026-10-23 在独立抖音推荐标签中核验，没有启动采集任务，也没有改动用户原有推荐标签。

- 打开普通侧栏并切换「TA的作品」后，网站原生 `GET /aweme/v1/web/user/profile/other/` 返回 `status_code=0`；「延晨的动漫窝」的 `user.ip_location` 为「IP属地：安徽」。说明侧栏触发的响应可以提供该字段，不代表每次都能捕获。
- 主动补发接口请求（包括使用已观察到的参数和请求头）返回 HTTP 200、空响应体；没有取得可核验的用户对象。HTTP 200 不作为取数成功。
- 直接请求公开主页 HTML 得到「验证码中间页」，没有 `ipLocation` 数据。没有尝试通过验证或绕过限制。
- 因此本次生产代码只落实用户指定的完整主页补采开关，保留已验证的侧栏响应读取；主动接口补采尚未接入，不能宣称已实现稳定的三阶段获取。文案按实际实现描述。
- 所有请求参数只在临时浏览器会话内使用，未保存 Cookie、签名或设备凭据。独立测试标签已关闭。
