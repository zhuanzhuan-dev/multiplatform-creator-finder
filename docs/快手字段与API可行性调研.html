04 / API 判断05 / 09

接口边界

官方 API 能读授权用户资料，
当前解决不了任意达人快手号。

官方开放平台

GetUserInfo

GET https://open.kuaishou.com/openapi/user_info
  • 前提：应用注册与用户授权 user_info。
  • 文档字段：name、sex、fan、follow、head、bigHead、city。
  • 文档未列：快手号、主页 URL。
登录态网站接口

网页 GraphQL / 私有响应

https://www.kuaishou.com/graphql
  • 公开项目利用浏览器登录态和网站内部查询。
  • 可参考 user_id、昵称、头像、简介、计数和作品分页。
  • 字段与接口随网页变化；当前公开查询样例没有快手号。
