# V1.0.25 跨网页悬浮入口

本地构建位于 `dist/`，代码保持未提交。

## 功能与入口

通过浏览器工具栏的插件图标或网页悬浮球打开侧栏，点击右上角“设置”，进入“悬浮球设置”。

- 普通 HTTP、HTTPS 顶层网页显示悬浮入口，空闲和任务结束后均可打开侧栏。
- 默认 36×36 像素，开启“缩小悬浮球”后为 28×28 像素。
- 支持横向、纵向拖动和方向键移动。拖动结束保存位置，点击打开侧栏。
- 大小和位置在同一浏览器配置下跨网页保存和同步；调整大小或窗口后保持在可见区域。
- 隐藏只改变入口显示，采集任务继续运行。
- 采集逻辑继续按平台和页面路由运行；普通网页只注入轻量悬浮入口。

## 隐藏范围

| 范围 | 生效规则 | 恢复方式 |
| --- | --- | --- |
| 本次访问 | 仅隐藏当前标签页中的当前文档，切换 Tab 和更新任务状态保持隐藏 | 刷新、重新访问或点击“取消本次隐藏” |
| 当前网站禁用 | 按精确域名保存，同域名所有标签页生效，子域名分别设置 | 访问该网站，在设置中点击“恢复当前网站” |
| 永久禁用 | 所有普通网页隐藏，浏览器重启后保持 | 在设置中打开“启用悬浮球” |

各范围独立生效：恢复某个范围后，其他范围的隐藏规则继续生效。网站设置按域名区分，不区分协议、端口和路径。本次访问以当前文档生命周期为准，单页应用内部路由变化与浏览器前进后退缓存恢复仍保留本次隐藏。

## 本地验收

1. 在扩展管理页重新加载指向 `dist/` 的扩展，确认版本为 1.0.25。
2. 刷新普通网页，确认默认 36px；打开设置勾选缩小，确认 28px，并检查其他网页同步大小。
3. 向左、向上拖动按钮；刷新、切换网页和缩放窗口，确认位置保存且按钮完整可见。
4. 选择“本次访问”并隐藏。切换 Tab 再返回、打开关闭侧栏，确认保持隐藏；刷新网页应恢复。也可从工具栏进入设置，点击“取消本次隐藏”。
5. 选择“当前网站禁用”并隐藏；刷新和打开该域名的新标签页仍隐藏，其他域名继续显示。点击“恢复当前网站”后同域页面恢复。
6. 选择“永久禁用”并隐藏；其他网页和新网页均隐藏。重新打开全局“启用悬浮球”，未被网站或本次规则隐藏的页面恢复。
7. 叠加网站禁用和全局禁用，单独恢复全局后网站仍隐藏；再恢复网站后显示。
8. 运行任务期间隐藏或恢复悬浮球，确认任务状态、计数和暂停/停止功能正常。
9. 在抖音、飞瓜页面确认仅一个入口；设置打开时切换标签页，确认当前域名随之更新。

Chrome 内置页面、Chrome 网上应用店等受保护页面由浏览器限制脚本注入。网页站点访问权限需允许插件运行。重新加载扩展、页面加载完成及切换标签页时，自动为缺少入口的普通网页补装悬浮脚本，显示前读取隐藏设置。

## 检查记录

`pnpm check` 包含类型检查、自动化测试、构建与 dist 校验。自动化覆盖位置、边界、旧设置迁移、拖动防误触、大小切换、持久化隐藏、临时隐藏隔离、任务状态变化保持隐藏，以及入口替换保留当前文档隐藏状态。

本地网页预览使用模拟浏览器 API，已检查大小开关、三种隐藏操作和恢复按钮。真实 Chrome 扩展的跨标签页、重启与站点权限效果按上述步骤验收；预览结果不代表真实扩展验收通过。
