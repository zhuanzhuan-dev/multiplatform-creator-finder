## 产品概述

**多平台自动找号助手** 是一款 Chrome 浏览器扩展，能够从多个内容平台的推荐流、热门榜、数据工具中自动发现符合筛选规则的达人和视频，并将观察结果同步到云端研究台。

### 核心能力

- ✅ **六大平台覆盖**: 抖音推荐、快手推荐、B站推荐流、B站综合热门、飞瓜视频库、星图达人广场
- ✅ **智能筛选**: 粉丝数、点赞数、播放量、视频时长、内容类别关键词匹配
- ✅ **自动采集**: 后台持续运行，自动翻页、读取账号资料、判断符合度
- ✅ **定时启动**: 配置每周执行时间（抖音），无人值守自动运行
- ✅ **正向互动**: 可选自动点赞、收藏、关注，模拟真实用户行为（抖音）
- ✅ **并行运行**: 多个平台任务同时采集，独立管理，统一上传
- ✅ **数据同步**: 自动上传到云端研究台，团队共享候选账号

### 适用场景

- 达人发掘：为商务拓展、内容合作寻找符合品牌调性的创作者
- 赛道研究：观察特定类目的创作生态、爆款规律、内容趋势
- 竞品分析：批量采集行业头部/新锐账号的内容指标

## 安装与配置

### 环境要求

- **Chrome 浏览器**: 版本 ≥ 120
- **操作系统**: macOS / Windows / Linux
- **研究台账号**: 公司 SSO 账号（用于连接研究台同步数据）

以下仅在从源码自行构建时需要，商店安装无需准备：

- **Node.js**: 版本 22
- **pnpm**: 版本 10

### 安装方式

#### 方式 1：从 Chrome 应用商店安装（推荐）

1. 访问扩展商店页面：[https://chromewebstore.google.com/detail/gakciglpbjghijhibockcoohjncemobn](https://chromewebstore.google.com/detail/gakciglpbjghijhibockcoohjncemobn)
2. 点击「添加至 Chrome」按钮
3. 在弹出窗口中点击「添加扩展程序」
4. 安装完成后，地址栏右侧出现扩展图标（雷达样式）

**优势**：
- ✅ 一键安装，无需构建
- ✅ 自动更新到最新版本
- ✅ Chrome 官方审核，安全可靠

#### 方式 2：团队一键安装（macOS 内部开发）

1. 下载项目代码包
2. 双击 `团队一键安装.command` 文件
3. 脚本会自动检查 Node.js 版本、安装依赖、构建扩展
4. 按提示在 Chrome 中加载 `dist/` 文件夹

#### 方式 3：开发者模式加载（开发调试）

1. **构建扩展**（如已有 dist 文件夹可跳过）
   ```bash
   # 确保 Node.js 22 和 pnpm 10 已安装
   pnpm install --frozen-lockfile
   pnpm build
   ```

2. **加载到 Chrome**
   - 打开 Chrome，访问 `chrome://extensions/`
   - 开启右上角「开发者模式」
   - 点击「加载已解压的扩展程序」
   - 选择项目中的 `dist/` 文件夹（**不是根目录**）

3. **验证安装**
   - 扩展列表中显示「多平台自动找号助手 V1.1.9」
   - 地址栏右侧出现扩展图标（雷达样式）

### 首次启动

安装完成后，点击 Chrome 工具栏的扩展图标，侧边栏会打开并显示：

> 「登录并连接研究台」

请继续下一节完成连接配置。

## 首次连接研究台

### 什么是研究台？

**研究台** 是云端协作平台，用于：
- 接收所有设备采集的观察数据
- 展示候选达人列表，支持筛选、标注、分配
- 管理设备配对和权限

研究台地址：[https://fai.zhuanspirit.com/creators](https://fai.zhuanspirit.com/creators)

### 配对流程

1. **打开侧边栏**，点击「登录并连接研究台」按钮
2. 浏览器自动打开配对页面（会跳转到公司 SSO 登录）
3. 登录后，页面显示配对码（6 位字母数字）
4. 在侧边栏输入配对码，点击「确认配对」
5. 配对成功后，侧边栏顶部显示：  
   > 「研究台已连接 · 结果自动同步」

### 检测连接状态

点击侧边栏右上角的「设置」齿轮图标，在弹窗中可以看到：
- 当前连接的账号 ID
- 「重新连接」按钮（授权失效时使用）

### 本地测试模式

如果你只想在本机测试功能，不上传数据：
1. 打开「设置」弹窗
2. 找到「开发调试」区域
3. 勾选「本地测试（不连接、不上传）」

此模式下：
- 不需要配对研究台
- 采集结果只存储在本机浏览器
- 侧边栏顶部显示黄色提示：「新任务使用本地测试模式」

  - **符合条件**: 通过初筛的内容次数

  - 重复发现
  - 已标记不感兴趣
  - 跳过直播 / 跳过图文 / 跳过广告
  - 类型未确认
  - 账号资料读取失败
- **最近记录**: 最近 5 条处理记录，每条显示：
  - 账号头像、名称
  - 处理结果标签（符合条件/需人工确认/跳过等）
  - 来源平台（抖音/快手/B站）
  - 处理原因
  - 时间戳
  - 「视频」按钮：点击查看该账号采集到的视频列表
- **本机近 24 小时记录（N）**: 打开扩展内完整历史记录页
- **研究台最近记录**: 打开研究台最近记录页

**标签 1：运行设置**

- 任务目标
- 定时任务
- 其他选项

**标签 2：视频与账号规则**
- 视频与账号条件

## 六大平台任务

本插件支持六个独立的平台任务，可同时运行，互不干扰。每个平台的采集内容、前置条件、配置项略有不同。

### 平台对比表

| 平台 | 采集内容 | 需要登录 | 自动翻页 | 定时启动 | 正向互动 | 数据上传 |
|------|---------|---------|---------|---------|---------|---------|
| 抖音 | 推荐流视频 | 建议登录 | ✅ | ✅ | ✅ | ✅ |
| 快手 | 推荐流视频 | 建议登录 | ✅ | ❌ | ❌ | ✅ |
| B站推荐 | 推荐流视频 | **必须** | ✅ API批量 | ❌ | ❌ | ✅ |
| B站热门 | 综合热门视频 | **必须** | ✅ API批量 | ❌ | ❌ | ✅ |
| 飞瓜 | 视频库列表 | 建议登录 | ✅ | ❌ | ❌ | 默认关闭 |
| 星图 | 达人广场列表 | 建议登录 | ✅ | ❌ | ❌ | 默认关闭 |

### 1. 抖音推荐流

**采集内容**: 抖音首页推荐流中的短视频

#### 前置条件

- 打开 [https://www.douyin.com/?recommend=1](https://www.douyin.com/?recommend=1)
- 建议先登录抖音账号（未登录可能触发验证）

#### 使用步骤

1. 在侧边栏选择「抖音推荐」平台
2. 配置「任务设置」（可选，首次使用已有默认值）
3. 点击「开始新一轮」
4. 插件自动：
   - 读取当前视频的标题、作者、点赞数、时长
   - 判断视频类型（排除直播、图文、广告）
   - 打开作者侧栏，读取粉丝数、简介、作品列表
   - 根据规则判断是否符合条件
   - 停留配置的时长
   - 点击「下一个」翻页
5. 达到目标（时间或数量）后自动停止

#### 独有功能

- ✅ **定时启动**: 可配置每周特定时间自动启动任务
- ✅ **正向互动**: 符合条件的视频可自动点赞、收藏、关注作者
- ✅ **标记不感兴趣**: 淘汰的内容自动标记为「不感兴趣」
- ✅ **低粉新号例外**: 粉丝不足但作品数少、均赞高的账号可通过

#### 已知限制

- 侧栏读取失败最多重试 3 次
- 连续 3 次翻页失败会自动暂停

### 2. 快手推荐流

**采集内容**: 快手推荐页视频

#### 前置条件

- 打开 [https://www.kuaishou.com/new-reco](https://www.kuaishou.com/new-reco)
- 建议先登录快手账号

#### 使用步骤

1. 在侧边栏选择「快手推荐」平台
2. 点击「开始新一轮」
3. 插件自动：
   - 读取当前激活的视频卡片
   - 后台打开作者主页，获取粉丝数、简介、作品
   - 根据规则判断
   - 点击「下一条」按钮翻页

#### 功能差异

- ✅ 支持自动翻页和停留时长配置
- ❌ **不支持定时启动**（目前仅抖音支持）
- ❌ **不支持正向互动**（点赞/收藏/关注）
- ❌ **不支持「不感兴趣」标记**
- ❌ **不触发低粉新号例外**（快手作品列表无法验证完整性）

#### 已知限制

- 检测到验证码、登录提示或访问频繁时会自动暂停
- 预加载的相邻卡片不参与采集（只处理当前激活卡片）

### 3. B站推荐流 & 综合热门

**采集内容**:
- **B站推荐**: 首页推荐流视频 ([https://www.bilibili.com/](https://www.bilibili.com/))
- **B站热门**: 综合热门榜视频 ([https://www.bilibili.com/v/popular/all](https://www.bilibili.com/v/popular/all))

#### 前置条件

- **必须先登录 B站账号**（未登录无法调用接口）
- 打开对应页面（首页或综合热门页）

#### 使用步骤

1. 在侧边栏选择「B站首页推荐」或「B站综合热门」
2. 点击「开始新一轮」
3. 插件自动：
   - 通过 B站 API 批量获取视频列表
   - 每批 20-30 条，批次间延迟 5-12 秒（可配置）
   - 读取视频标题、分区、播放量、点赞、弹幕、收藏等
   - 调用接口获取作者粉丝数
   - 根据 B站专用规则判断

#### 独特机制

- ✅ **API 批量采集**: 不依赖页面滚动，效率更高
- ✅ **早期窗口规则**: 发布后 3 天内的视频使用不同的播放量门槛
- ✅ **分区过滤**: 可配置排除「动漫」「电影」等分区
- ✅ **双独立任务**: 推荐流和综合热门分别保存进度、计数、状态

#### 功能差异

- ❌ **不支持定时启动**
- ❌ **不支持正向互动**
- ❌ **不支持低粉新号例外**

#### 已知限制

- 推荐内容耗尽时接口返回 code=-62011
- 综合热门最后一页 no_more=true

### 4. 飞瓜视频库

**采集内容**: 飞瓜数据视频库列表（[https://dy.feigua.cn/app/#/video/library/all](https://dy.feigua.cn/app/#/video/library/all)）

#### 前置条件

- 打开飞瓜视频库页面
- 建议先登录飞瓜账号

#### 使用步骤

1. 在侧边栏选择「飞瓜视频库」平台
2. 可选配置：
   - 每批采集页数（默认 50 页）
   - 翻页等待时间（默认 4-6 秒随机）

## 筛选规则配置

筛选规则决定哪些内容和账号会被标记为「符合条件」或「需人工确认」。不同平台使用不同的规则集；各任务独立保存，改一边不会改另一边。平台隔离、打开会不会重置、正负向词怎么命中，见 [运行规则](./运行规则.md)。

### 通用规则（抖音 / 快手）

在侧边栏「任务设置」→「视频与账号规则」标签页配置。

#### 1. 视频与账号条件

| 字段 | 默认值 | 说明 |
|------|-------|------|
| 最短视频（秒） | 60 | 短于此时长的视频直接跳过 |
| 最低点赞 | 3000 | 基础通过线 |
| 优选点赞 | 4000 | 高于此值可获得加分 |
| 最低粉丝 | 10,000 | 粉丝数下限 |
| 最高粉丝 | 5,000,000 | 粉丝数上限 |

#### 2. 低粉新号例外

启用后，粉丝数低于「最低粉丝」的账号，如果满足以下条件，仍可通过：

| 字段 | 默认值 | 说明 |
|------|-------|------|
| 启用开关 | ✅ | 勾选后生效 |
| 最多作品数 | 10 | 作品数量 ≤ 此值 |
| 最低平均点赞 | 3000 | 主页平均点赞 ≥ 此值 |
| 要求作品列表完整加载 | ✅ | 侧栏显示「暂无更多」或「到底了」 |

**适用场景**: 发掘粉丝不多但内容质量高的新锐创作者。

**注意**: 快手不支持验证作品列表完整性，因此快手任务不触发此例外规则。

#### 3. 想找的内容（内容类别）

通过关键词匹配标题、话题标签、昵称、简介，命中后获得加分。

**默认类别**:

| 类别 | 加分 | 受众描述 |
|------|------|---------|
| 美食 | 20 | 广泛受众 |
| 剧情 | 20 | 18-30 倾向 |
| 游戏PC | 20 | 男性偏高 |
| 体育/才艺 | 15 | - |
| Vlog | 15 | - |
| AI内容 | 15 | - |
| 王者荣耀 | 10 | - |

**编辑类别**:
- 点击类别名称展开详情
- 修改「类目名称」「命中加分」「受众描述」「关键词」
- 关键词用逗号或空格分隔
- 点击「删除这个类目」移除
- 点击「＋ 添加内容类别」新增

**正向互动设置**（详见 [正向互动](#正向互动) 章节）:
- ☑ 点赞 Z / ☑ 收藏 C / ☑ 关注 G
- 每项配额上限百分比（0-100%，默认 10%）
- 「一键全选」 / 「全部取消」按钮

**评分逻辑**:
- 平均点赞 ≥10,000: +20 分
- 平均点赞 4,000-10,000: +10 分

- 粉丝 1-10 万 或 100-500 万: +10 分

**等级判定**:
- **S级**: 粉丝 10-300 万 且 均赞 ≥4000 且 有类别匹配
- **A级**: 粉丝 1-100 万 且 均赞 ≥3000 且 有类别匹配
- **B级**: 其他通过者

**命中规则**:
- 正向类别未匹配但符合其他条件 → 标记为「需人工确认」
- 排除关键词优先级最高，命中后直接剔除
- 完整命中顺序、准召口径与语义接口现状见 [运行规则](./运行规则.md)

**默认排除**: 和平精英、我的世界、迷你世界、光遇

**匹配范围**: 标题、话题、昵称、简介

**触发机制**: 命中任一关键词，直接剔除，不进入符合条件

## 定时任务

**定时任务** 允许你配置每周特定时间自动启动采集任务，无需人工值守。

### 功能说明

- **适用平台**: 目前仅支持 **抖音推荐流**
- **启动方式**: 到点后自动打开抖音推荐页（或复用已有页面），开始新一轮采集
- **运行目标**: 独立配置，与手动启动的目标不同
- **延迟启动**: 如果到点时浏览器未打开或电脑休眠，恢复后会在一定时间内补启动

### 配置步骤

1. 在侧边栏「任务设置」→「运行设置」标签页，找到「定时任务」区域
2. 勾选「启用定时任务」
3. **执行星期**: 点击周一到周日按钮，选中的星期高亮显示（默认：周二至周六）
4. **执行时间**: 默认 6 个时间点
   - 11:15
   - 13:30
   - 16:00
   - 18:00
   - 20:00
   - 23:00
   - 点击「＋ 添加时间」可新增时间点
   - 点击时间右侧的 ❌ 删除该时间点
5. **任务目标**: 选择停止方式
   - 按时间：运行时长（分钟，默认 60）
   - 按视频数：视频数量（条，默认 100）
   - 双重限制：任一达到即停止
6. **允许延迟启动**: 如果到点时浏览器未打开，恢复后 N 分钟内仍可补启动（默认 10 分钟）
7. **☑ 优先复用插件创建的抖音任务页**: 勾选后，如果已有插件创建的抖音推荐页仍打开，直接在该页恢复任务；否则新建标签页
8. 点击「应用默认预设」可快速恢复默认配置
9. 点击「保存设置」

### 使用建议

- **电脑保持开机**: 定时任务需要浏览器运行，关机或休眠时无法启动
- **窗口可最小化**: 任务运行时，浏览器窗口可最小化，不影响后台采集
- **检查定时结果**: 运行卡片「查看详情」中会显示「下次定时」和「定时结果」

### 注意事项

- 定时启动仅支持抖音，快手、B站、飞瓜、星图暂不支持
- 定时任务的运行目标与手动启动的「任务目标」是分开的，互不影响
- 到点时如果已有任务运行中，定时任务会跳过，等待下次时间点

## 正向互动

**正向互动** 是指插件在采集过程中，对符合条件的内容自动执行点赞、收藏、关注等操作，模拟真实用户行为。

### 功能说明

- **适用平台**: 目前仅支持 **抖音推荐流**
- **触发条件**: 只有明确通过筛选且命中正向类目的内容可互动，「需人工确认」的内容跳过
- **配额限制**: 每项操作的执行次数受配额限制，配额 = 本轮新处理普通视频数 × 配额比例（向下取整）
- **去重机制**: 点赞、收藏按视频去重；关注按作者去重

### 配置步骤

1. 在侧边栏「任务设置」→「视频与账号规则」标签页，找到「想找的内容」区域
2. 展开「正向互动设置」
3. 勾选需要的操作：
   - ☑ **点赞 Z**: 发送键盘 Z 键
   - ☑ **收藏 C**: 发送键盘 C 键
   - ☑ **关注 G**: 发送键盘 G 键
4. 设置「每项配额上限百分比」（0-100 整数，默认 10%）
   - 例如：本轮处理 100 条普通视频，10% 配额 = 10 次
   - 预设按钮：5% / 10% / 20%
5. 点击「一键全选」快速勾选所有操作，点击「全部取消」取消所有操作
6. 点击「保存规则」

### 执行机制

- **按键发送**: 插件通过模拟键盘按键（Z/C/G）触发抖音的互动操作
- **执行前后不检查**: 不验证平台互动状态，已有操作可能被切换取消
- **配额占用持久化**: 按键发送前记录配额占用，发送不确定时保留占用且不重试，防止重复请求超额
- **去重**: 插件按本轮已发送记录去重，不重复对同一视频点赞/收藏，不重复对同一作者关注

### 查看互动统计

运行卡片「查看详情」中显示：
- 本轮互动上限：配额总数
- 点赞次数：已发送 Z 键次数
- 收藏次数：已发送 C 键次数
- 关注次数：已发送 G 键次数
- 已用配额：已占用的配额数

### 注意事项

- **发送成功 ≠ 操作成功**: 插件只负责发送按键，不验证平台是否真正执行了点赞/收藏/关注
- **配额计算**: 只有新处理的普通视频计入配额基数，重复读取、跳过的直播/图文/广告不增加配额
- **暂停继续**: 暂停后继续，配额保留；开始新一轮时，配额重新计算
- **仅抖音**: 快手、B站、飞瓜、星图暂不支持正向互动

## 统计指标口径

为避免误解，以下是侧边栏和历史页中各指标的准确定义。

### 主要指标

| 指标 | 定义 |
|------|------|
| **今日已刷** | 按北京时间自然日统计已处理且有可识别标识的内容，同一内容当天只计一次，包含直播、图文、广告与其他跳过内容 |
| **本轮已刷** | 当前轮次进入首次处理的内容数，已有本地处理记录的内容直接跳过；开始新一轮时重置 |
| **符合条件** | 通过初筛的内容次数，包含重复发现与需要人工确认的候选 |
| **新发现账号** | 本轮首次加入本机账号索引的账号数 |
| **需人工确认** | 本轮新发现账号中需要人工确认的累计数量，与新发现账号有包含关系；工作台处理后不会回减 |
| **重复发现** | 通过初筛但已存在于本机账号索引的次数 |
| **本轮已同步** | 当前 runId 的记录收到服务端成功或重复确认的数量；补传旧轮次不增加当前轮次计数 |
| **跳过原因** | 直播、图文、广告、类型未确认和账号资料读取失败分别记录；广告与媒介类型重叠时归入广告，避免重复计数 |

### 24 小时窗口

- **历史记录**: 从当前时间往前推 24 小时，跨轮次保留
- **自动清理**: 每次写入及后台每 5 分钟清理超过 24 小时的记录
- **查询严格**: 每次查询严格排除超过 24 小时的记录

### 处理结果代码

历史记录表格中的「处理结果」徽章，对应的代码和含义：

| 徽章 | 代码 | 分类 |
|------|------|------|
| 符合条件 | ACCEPTED | good |
| 需人工确认 | *REVIEW* | review |
| 跳过广告 | AD_SKIPPED | reject |
| 跳过图文 | PHOTO_SKIPPED | reject |
| 类型未确认 | UNKNOWN_TYPE_SKIPPED | reject |
| 跳过直播 | *LIVE* | reject |
| 重复发现 | *DUPLICATE* | reject |
| 资料未读全 | *PANEL* / *MISSING* / *INVALID* | review |
| 未符合条件 | REJECT / BLACKLIST / RISK / TOO_SHORT / DURATION / LIKES / PLAYS / CONTENT_EXCLUDED / DIGITAL | reject |
| 浏览已采集 | FEIGUA_OBSERVED / XINGTU_OBSERVED | review |

### 平台来源

侧栏和历史页显示的平台标签：

| 代码 | 显示名称 |
|------|---------|
| douyin | 抖音 |
| kuaishou | 快手 |
| bilibili | B站 |
| feigua | 飞瓜 |
| xingtu | 星图 |

### 数据属性

- **今日累计**: 保存在 `chrome.storage.local` 的 `draDailyStats` 中，保留最近 30 天的每日总数，以及当天用于去重的内容标识
- **跨轮次**: 今日累计跨轮次、重启侧栏和浏览器后保留，跨天从零显示
- **本机数据**: 数据属于当前浏览器配置，不在多台电脑之间同步；卸载插件或清除扩展存储会清除
- **功能启用前**: 功能启用前的数据不进行推算补录

|-----------|------|---------|---------|
| dra-observations | 完整观察记录（达人、视频、指标、判断、原始字段） | 无上限（依赖 unlimitedStorage 权限） | 定时任务每 60 分钟清理 24 小时后且已上传确认或不符合上传条件的记录 |
| dra-decision-history | 24 小时决策历史（账号名、判断代码、原因、时间） | 无上限 | 定时任务每 5 分钟清理超过 24 小时的记录 |
| dra-local-raw-samples | 调试采样（DOM、类型判断、页面原始字段） | 最多 200 条 / 25 MB，单条不超过 1 MB | 超限时自动删除最早样本 |

**chrome.storage.local（配置与队列）**

内容：settings, rules, state（任务状态）, seenVideos（去重）, creatorIndex, outbox（上传队列）, cloudAuth（配对凭据）, pairing, feiguaState, xingtuState, kuaishouState, bilibiliState

上传队列容量：最多 1000 条，达到容量时保留未上传数据并继续排空队列，不阻止新采集

### 数据导出

**完整观察导出**
- 触发：侧栏顶部「导出本地完整观察」按钮
- 格式：JSON，文件名 `采集观察-<日期>.json`
- 内容：从 IndexedDB 读取全部 records，按 sequence 索引顺序

**调试采样导出**
- 触发：侧栏「设置」→「开发调试」→「导出采样」按钮
- 格式：JSON 包含 `{schemaVersion, exportedAt, samples}`
- 文件名：`推荐流原始采样-<时间戳>.json`
- 清空：单独按钮「清空采样」

### 数据上传

- **上传接口**: `https://kigrzhmcphrkqtuqthwb.supabase.co/functions/v1/ingest`
- **契约版本**: No Swipe observation batch `contract_version = 2`
- **上传队列**: 独立的后台闹钟处理，翻页确认只等待本地持久化与排队，不等待网络请求
- **失败重试**: 网络失败重试，有效授权恢复后继续同步
- **队列串行**: 按采集时间优先排序，同批只合并连续同任务记录
- **断开处理**: 暂停、停止后已有队列继续同步，浏览器重启时重建上传任务

### 隐私保护

- **本地处理**: 所有内容筛选、规则判断在本机浏览器完成，不发送到第三方服务器
- **按需上传**: 只有符合条件、需人工确认、跳过的内容才上传到研究台
- **不采集凭据**: 采样数据清除脚本、表单值、敏感属性与凭据字段
- **不抓取网络响应**: 采样仅保存 DOM 和页面可见字段，不监听网络请求
- **配对凭据**: 配对凭据存储在本机 `chrome.storage.local` 的 `cloudAuth` 键，不外传
- **本地测试模式**: 启用后，数据仅保存在本机，不上传研究台

### 数据清理

**自动清理**
- 观察记录：每 60 分钟清理 24 小时后且已上传确认或不符合上传条件的记录
- 决策历史：每 5 分钟清理超过 24 小时的记录
- 上传队列：队列满时优先删除已成功（written, duplicate, dry-run）的旧记录

**手动清理**
- 清空调试采样：侧栏「设置」→「开发调试」→「清空采样」
- 卸载插件：Chrome 扩展管理页删除插件，会清除所有本地数据
- 清除扩展存储：Chrome 设置 → 隐私和安全 → 网站设置 → 查看所有网站的权限和数据存储 → 搜索「扩展」→ 删除数据

## 常见问题

### 安装与配置

**Q1: 安装后扩展图标显示灰色，点击无反应？**

A: 检查以下几点：
1. 打开 `chrome://extensions/`，检查扩展是否启用
2. 刷新浏览器或重启 Chrome
3. 查看 Chrome 开发者工具控制台是否有错误（按 F12）
4. 如果是开发者模式加载：确认加载的是 `dist/` 文件夹，不是源码根目录

**Q2: Chrome 应用商店打不开或无法安装？**

A: 可能原因：
- 网络问题，尝试使用 VPN 或稍后重试
- Chrome 版本过低，请更新到最新版本
- 地区限制，联系团队获取开发者加载方式

**Q3: 提示「Chrome 版本过低」？**

A: 本插件要求 Chrome ≥ 120，请更新 Chrome 浏览器到最新版本。

**Q4: 配对研究台时提示「授权失效」？**

A: 可能原因：
- 配对码输入错误
- 配对码已过期（5 分钟有效期）
- 公司 SSO 登录失败

解决方法：
1. 点击「重新连接」重新生成配对码
2. 确认公司 SSO 账号可正常登录
3. 检查网络是否正常

---

### 任务运行

**Q5: 点击「开始新一轮」后没有反应？**

A: 检查以下几点：
1. **抖音/快手**: 确认已打开推荐页（抖音 `/?recommend=1`，快手 `/new-reco`）
2. **B站**: 确认已登录 B站账号
3. **飞瓜/星图**: 确认已打开视频库/达人广场页面
4. 查看运行卡片「查看详情」中的「暂停原因」或「具体错误」

**Q6: 任务运行一会儿就自动暂停了？**

A: 常见原因：
- **平台验证**: 抖音/快手/飞瓜/星图检测到验证码或登录提示，需人工处理后点击「继续本轮」
- **网络异常**: 页面加载失败，刷新页面后点击「继续本轮」
- **达到目标**: 本轮已达到时间或数量目标，点击「开始新一轮」继续
- **侧栏读取失败**: 抖音侧栏打开失败，最多重试 3 次后暂停，刷新页面后继续
- **翻页失败**: 连续 3 次翻页失败，刷新页面后继续

查看运行卡片「查看详情」中的「暂停原因」了解具体原因。

**Q7: 为什么有些视频被跳过了？**

A: 插件会跳过以下类型的内容：
- **直播**（包括图文直播）
- **图文内容**（非视频）
- **广告**
- **类型未确认**（无法从 DOM 判断类型）
- **视频时长不足**（短于「最短视频」设置）

跳过的内容会记录在「本轮已刷」展开区，点击「跳过直播」「跳过图文」「跳过广告」等查看统计。

**Q8: 为什么符合条件的账号被标记为「需人工确认」？**

A: 以下情况会标记为「需人工确认」：
- **抖音/快手**: 正向类别未匹配但符合其他条件
- **B站**: 粉丝数缺失（接口未返回）
- **抖音**: 账号资料面板读取不完整

这些账号仍会上传到研究台，由人工在工作台复核。

**Q9: 定时任务没有按时启动？**

A: 检查以下几点：
1. 确认「定时任务」已启用，执行星期和时间已正确配置
2. 到点时浏览器是否打开（关机/休眠时无法启动）
3. 查看运行卡片「查看详情」中的「定时结果」，确认是否启动
4. 允许延迟启动时间是否足够（默认 10 分钟）

**Q10: 正向互动（点赞/收藏/关注）没有执行？**

A: 检查以下几点：
1. 确认「正向互动设置」中勾选了对应操作
2. 确认配额比例不为 0
3. 查看运行卡片「查看详情」中的「点赞次数」「收藏次数」「关注次数」，确认是否已发送按键
4. 配额可能已用完（配额 = 本轮新处理普通视频数 × 配额比例）
5. 正向互动只对明确通过筛选且命中正向类目的内容生效，「需人工确认」的内容跳过

注意：插件只负责发送按键，不验证平台是否真正执行了点赞/收藏/关注。

### 数据与统计

**Q11: 「今日已刷」数字不准确？**

A: 「今日已刷」按北京时间自然日统计，同一内容当天只计一次。如果：
- 跨天后从零开始，符合预期
- 功能启用前的数据不进行推算补录
- 卸载插件或清除扩展存储会清除历史数据

**Q12: 历史记录页只显示部分记录？**

A: 历史记录从当前时间往前推 24 小时，超过 24 小时的记录自动清理。每页最多显示 50 条，点击「下一页」查看更多。

**Q13: 导出的 JSON 文件打不开？**

A: 导出的 JSON 文件较大时，建议使用专业的 JSON 查看器（如 VS Code、Sublime Text、在线 JSON Viewer）打开，不要用记事本。

**Q14: 飞瓜/星图采集的数据没有上传到研究台？**

A: 飞瓜和星图默认只存本机，不上传研究台。如需上传，在对应任务页底部的「设置」折叠区，勾选「上传开关」（当前版本此功能仍在开发中，默认关闭）。

### 性能与稳定性

**Q15: 任务运行时浏览器卡顿？**

A: 正常情况下，插件后台运行不会占用大量资源。如果卡顿：
1. 检查是否同时运行了多个平台任务
2. 检查是否开启了「原始采样」（会占用额外存储和 CPU）
3. 关闭其他不必要的浏览器标签页
4. 重启浏览器

**Q16: 关掉浏览器后任务会继续运行吗？**

A: **不会**。任务需要浏览器和任务页面保持打开状态。关闭浏览器、电脑休眠、断网都会导致任务中断。

但以下操作不影响后台运行：
- 窗口最小化
- 切换标签页或窗口
- 使用其他软件

**Q17: Service Worker 重启后任务状态丢失？**

A: 任务状态保存在 `chrome.storage.local`，Service Worker 重启后会自动恢复。如果发现状态丢失，可能是：
- 扩展被重新加载（需刷新页面并手动继续任务）
- 浏览器清除了扩展存储

### 规则与配置

**Q18: 修改规则后需要重启任务吗？**

A: 是的。规则修改后，点击「保存规则」或「保存设置」，然后：
- 如果任务运行中，点击「停止本轮」→「开始新一轮」
- 如果任务已停止，直接点击「开始新一轮」

新规则只对新一轮任务生效，已处理的内容不会重新判断。

**Q19: 如何恢复默认配置？**

A: 在「任务设置」中：
- 「运行设置」标签页：点击「应用随机预设」（单条停留）或「应用默认预设」（定时任务）
- 「视频与账号规则」标签页：手动修改回默认值（参考本手册中的默认值表格）

**Q20: 可以同时运行多个平台任务吗？**

A: 可以。各平台独立保存状态、进度、计数，可同时运行，互不干扰。上传队列串行处理，按采集时间优先排序。

**Q21: 改了抖音的「想找的内容」，快手 / B 站会一起变吗？每次打开设置会回到默认吗？**

A: 不会。想找的内容、排除词和门槛按任务分开存；关侧栏或重启 Chrome 读回上次已保存的配置。规则必须点「保存规则」才落盘。详见 [运行规则](./运行规则.md)。

**Q22: 正向词和排除词按什么规则命中？准不准？**

A: 标题、昵称、话题做规范化后的文字包含；排除词优先。正向没命中但硬门槛过了，仍留下给人工确认。不是语义理解，词太短或太泛会误伤。详见 [运行规则](./运行规则.md)。

### 其他

**Q23: 如何查看插件版本？**

A: 侧边栏顶部显示版本号（如 V1.1.9），或在 `chrome://extensions/` 查看「版本」字段。

**Q24: 插件会不会被平台检测为机器人？**

A: 插件模拟真实用户行为（停留时长、滚动、点击），并使用随机区间、批间延迟等机制降低检测风险。但无法保证 100% 不被检测，建议：
- 使用真实账号登录
- 配置合理的停留时长和翻页间隔
- 避免长时间连续运行
- 定期休息

**Q25: 遇到其他问题怎么办？**

A: 请联系开发团队，提供以下信息：
- 插件版本号
- Chrome 版本号
- 操作系统
- 问题描述和截图
- 运行卡片「查看详情」中的「暂停原因」或「具体错误」
- 浏览器控制台错误日志（按 F12 打开开发者工具）
