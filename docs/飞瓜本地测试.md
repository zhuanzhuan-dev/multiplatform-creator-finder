# 飞瓜视频库接入与本地测试

本次在 1.0.21 基础上接入飞瓜，飞瓜在 1.0.22 接入，当前构建版本为 1.0.26，构建目录为 `dist/`。代码与构建结果用于本地验收，Git 变更保持未提交状态，既有发布包保持原样。

## 使用流程

1. 在 Chrome 扩展管理页重新加载指向本项目 `dist/` 的扩展；首次加载时选择“加载已解压的扩展程序”。
2. 打开 `https://dy.feigua.cn/app/#/video/library/all`，刷新页面以加载新的内容脚本。
3. 在飞瓜设置视频筛选条件、时间范围和排序。
4. 在插件设置的“开发调试”中开启“本地测试”，并关闭定时运行，防止测试期间触发已有抖音定时任务。
5. 在规则设置的“飞瓜视频库”中编辑规避词，点击“保存规则”。
6. 在飞瓜采集设置中设置每批页数（默认 50 页）和随机翻页等待区间（默认 4–6 秒），保存后开始新一轮采集。每批页数接受 1–500 的整数，等待区间接受 1–30 秒且最大值大于或等于最小值。配置在新一轮生效。

## 业务规则

- 飞瓜只运行视频库 `#/video/library/all`。工作台、达人详情页及其他页面显示引导信息。
- 使用飞瓜页面已有筛选结果；抖音推荐流的视频时长、点赞、粉丝阈值和互动规则仅用于抖音。
- 默认规避词：meme、正能量、随拍、爱心、惊悚、恐怖、悲痛、社会百态。规避词独立保存，每轮开始时固定该轮配置。
- 检查标题、话题、热词、昵称。当前页或后续页命中规避词，移除本轮该账号的全部候选。
- 以飞瓜达人 ID 跨页去重；页面缺少 ID 时以规范化昵称去重。同名但 ID 不同的账号分别保留。
- 每个账号汇总一条候选，保留昵称、粉丝显示值、视频 ID、来源页及飞瓜达人链接。候选标记为待复核。
- 暂停保留本轮候选与去重状态；继续时优先恢复原飞瓜标签页，不可用时复用或新建视频库标签页。重新经过旧页面时跳过重复内容。列表未更新、分页不可识别、登录或验证提示出现时暂停。
- 每页保存后在配置区间内均匀随机等待，再点击下一页；列表稳定检测每 750 毫秒进行一次，最多等待 25 秒。随机等待仅用于降低访问频率，仍可能触发平台访问限制。
- 每批达到目标页数后自动暂停，保存候选、去重记录和建议休息截止时间（暂停后 3 小时）。界面提示风险并允许提前手动继续；到时间后保持暂停，等待用户继续。继续后按同一页数目标采集下一批，回读旧页面计数保持不变。
- 到达当前筛选末页或手动结束本轮后汇总到现有上传队列。末页与批次上限同时到达时优先结束，显示“飞瓜已采集到当前筛选的最后一页”。后一页排除只作用于本轮尚未上传的候选。
- 旧版视频数量目标迁移为默认 50 页；已保存候选和累计计数保留。建议休息是本轮提示，手动新开一轮仍可操作。
- 本地测试只保存本机记录。正式运行使用现有研究台连接；本地测试去重索引与正式索引分离。
- 飞瓜主页链接保留为来源资料，只有读到真实抖音主页链接时才填写抖音作者链接，飞瓜达人 ID 保持独立。
- 本轮最多暂存 900 个候选；达到容量时暂停并保留已有候选。上传队列空间不足时保留本地队列，完成已有上传后重试结束。
- 飞瓜采集复用启动、暂停、继续、结束和记录历史；抖音定时任务仍按原配置运行；飞瓜候选与抖音任务独立，飞瓜运行或暂停时均可按计划启动抖音。并行规则与验收见《多平台并行本地测试》。

## 验收清单

- 连续两页：已刷数量增长，分页按钮只触发一次，来源显示飞瓜视频库。
- 暂停：页码停止变化；继续后已采集的当前页保持去重。
- 后页排除：同一账号先入选、后命中规避词，最终队列没有该账号。
- 手动结束：本地测试队列包含最终候选，每账号一条，`source_platform=feigua`。
- 末页：下一页按钮禁用时结束本轮。
- 异常：下一页内容持续不变化时暂停；登录、验证和访问限制由用户处理。
- 回归：抖音推荐流仍使用原来的运行逻辑。
