# V1.0.21 发布说明

本版本将插件研究台入口迁移到公司内网，并修复升级后重新打开待授权配对时仍使用旧地址的问题。通过 GitHub Release 提供安装包。

## 本次更新

- “打开工作台”和配对授权页面统一使用 `https://fai.zhuanspirit.com/creators`，扩展域名权限同步更新。
- 重新打开有效期内的待授权配对时，根据当前研究台配置生成并保存授权页地址，保留原配对码、设备密钥和有效期。
- 安装说明、一键安装提示和插件内更新说明统一为内网访问流程。

## 安装与升级

1. 下载并解压 `multiplatform-creator-discovery-v1.0.21.zip`。
2. Chrome 扩展管理页开启“开发者模式”，加载解压后包含 `manifest.json` 的文件夹。已加载开发版的用户更新原目录后点击扩展刷新；源码开发用户加载本项目 `dist`。
3. 连接公司内网或 VPN，完成公司 SSO 和研究台登录；重新连接时在配对页确认授权。
4. 侧栏显示“研究台已连接”后，点击“检测连接”确认授权有效，再开始采集。

本次发布渠道为 GitHub Release，已解压扩展采用手动更新。
