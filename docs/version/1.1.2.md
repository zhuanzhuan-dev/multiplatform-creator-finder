# V1.1.2

修复全新安装时抖音任务界面无法显示的问题，并改善资料加载过程中的采集稳定性。

- 全新安装、没有历史任务时，手动选择抖音或自动跟随抖音推荐页，都能显示采集界面。
- 恢复飞瓜、快手任务时，即使旧状态的路由为空，也能显示所属平台界面。
- 抖音等待达人资料和作品列表稳定，读取过程中持续检查当前卡片与访问限制。
- 飞瓜等待完整行字段稳定至少 1.5 秒，最多等待 60 秒；读取期间页面跳转会中止本次读取。
- 头像、封面支持懒加载地址，排除占位地址。取得有效图片地址即可保存，不要求屏幕外图片完成下载。
- 飞瓜浏览采集补充加载复查、图片事件监听与完整路由变化识别，减少未加载时遗漏字段。

验证：243 项测试、类型检查、构建、dist 校验及 ZIP 打包通过。初始化、旧状态恢复和慢加载行为由回归测试覆盖；新电脑端到端采集尚未实测。

升级：下载 ZIP 解压，更新现有扩展目录并在 Chrome 扩展管理页重新加载，刷新采集网页后手动继续任务。保留原扩展安装以沿用本地数据。飞瓜上传保持现有关闭设置。
