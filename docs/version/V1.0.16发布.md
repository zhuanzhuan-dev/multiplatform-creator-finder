# V1.0.16

暂停后可以继续原轮次，保留计数、记录、目标和已运行时长。上传由独立后台任务处理，刷推荐流不再等待上传响应。

## 更新内容

- 增加“继续本轮”，暂停时间不计入任务时长；停止或达到目标后开始新一轮。
- 独立上传队列，暂停、停止后在连接有效时继续同步；旧轮次补传不增加本轮同步计数。
- 合并本轮结果与最近 5 条记录，新增按北京时间累计的今日已刷。
- 运行状态移入运行卡片，登录连接入口前置，连接管理与主题放入设置。
- 改善浅色材质与按钮高光，保持深色及跟随系统支持。
- 使用业务文案与正向、排除规则分组，保留已有用户规则。
- 分别记录直播、图文、广告及类型未确认的跳过原因。

## 验证

- `pnpm package`：类型检查、75 项单元测试、构建和 dist 文件验证通过。
- 浏览器回归：浅色/深色布局、最近 5 条、状态位置、设置菜单与暂停继续通过。
- 后台回归：切换标签页、暂停继续、重复刷新、调试连接恢复、冻结恢复、后台进程重启及定时停止通过。
- ZIP 内 21 个文件逐字节匹配 dist。

内容分类及授权异常使用模拟样例验证；真实抖音图文、广告样本与生产登录端到端尚未验收。
