# V1.0.20 发布说明

本版本在 V1.0.19 基础上增加当前推荐卡片的视频发布时间、当前视频封面和已加载作者作品封面的读取与上传，通过 GitHub Release 提供安装包。

## 发布时间

使用 `.video-create-time .time` 专用节点，排除无布局尺寸、隐藏、作者侧栏及视频文案内的节点。其他卡片与评论中的时间不参与全文推断。

支持“刚刚”、整数秒／分钟／小时／天前，以及完整 `YYYY-MM-DD` 日期和可选 `HH:mm[:ss]` 时间。相对时间以本次读取的 `observedAt` 为基准换算，标记为估算值；完整日期按北京时间解释，保留日／分钟／秒精度。缺少年份、月份相对时间、不合法或未来日期保留原文，换算值留空。

新增上传字段位于既有 `rpa_feedback` 对象：

| 字段 | 含义 |
|---|---|
| `published_at` | ISO UTC 时间；未知时 `null`。只有日期时为北京时间当日零点，须结合精度解释 |
| `published_time_text` | 时间节点原文，例如 `· 9小时前` |
| `published_time_precision` | `second`、`minute`、`hour`、`day` 或 `null` |
| `published_time_estimated` | 相对时间及不足秒精度的完整日期为 `true`，明确到秒的完整时间为 `false`，未知为 `null` |
| `published_time_source` | `dom:.video-create-time .time`，没有原文时为空 |

`observed_at` 仍表示插件采集时间。此次变更覆盖插件读取和上传请求体，不修改研究台展示或数据库结构。仅采集当前卡片时间，不涉及账号注册日期。

## 封面信息

当前视频优先读取当前卡片可见视频的 `poster`；缺失时尝试专用 `[data-e2e="video-cover"]`、`[data-e2e="feed-video-cover"]`、`.xgplayer-poster` 节点的图片或背景图，排除作者侧栏和任意头像图片。作者作品在已读取列表中补充 `currentSrc`／`src` 及常见懒加载属性。只保留 HTTP(S) 地址，排除 data/blob、已识别占位路径及已加载的 1–2 像素占位图。

新增字段均位于 `rpa_feedback`：

| 字段 | 含义 |
|---|---|
| `video_cover_url` | 当前视频封面 URL，未读取到时为空 |
| `video_cover_source` | `video.poster`、`cover-image` 或 `cover-background` |
| `creator_work_covers` | 已验证作者侧栏的作品封面列表；每项包含 `aweme_id`、`video_url`、`cover_url` |

作品封面优先按视频 ID 去重，缺少 ID 时按图片地址去重，最多 24 条。无法读取的视频 ID／链接留空；未读取作者侧栏或作者不匹配时列表为空。这是当前已加载作品的快照，不代表账号全部作品。仅上传 URL，不下载或永久托管图片。

## 测试与边界

- `pnpm check`：118 项测试、类型检查、构建与发行资源校验通过；覆盖日期与上传序列化、封面地址过滤、响应式／懒加载地址、去重、数量上限及作者归属。
- 隔离 Chrome 的 6 个场景通过，覆盖发布时间、视频 poster／专用图片／背景封面、头像与作者侧栏隔离、作品 ID／链接及懒加载列表。
- 模拟页面结果不能替代真实抖音节点覆盖率和后台保存验证。研究台展示这些字段需另行接入。

## 安装与使用

解压发行 ZIP，通过 Chrome 扩展管理页加载解压后的目录；现有开发版用户重新加载 `dist` 并刷新推荐页。采集结果仍写入研究台；新字段随既有 `rpa_feedback` 一并上传。
