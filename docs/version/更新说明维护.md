# 更新说明维护

更新说明的数据源为 `src/updates/releases.json`。扩展更新页读取此配置，默认展示安装的当前版本，历史版本折叠展示。

发布新版本时：

1. 运行 `pnpm version:patch` 更新补丁版本号；其他版本类型使用已有版本脚本。
2. 在 `releases.json` 顶部新增该版本，填写 `version`、`recordedAt`、`summary`、`items` 和 `notice`。`sourceCommit` 对新编写记录填写空字符串，对从历史恢复的记录填写来源提交。
3. 运行 `pnpm notes:generate`，生成 `docs/version/更新记录.md`。
4. 运行 `pnpm check`，核对说明与当前版本一致并更新 dist。发布 ZIP 时运行 `pnpm package`。

保留旧版本条目，页面代码无需随文案更新。`pnpm check` 会检查版本重复、当前版本说明缺失、内容缺失和生成文档不同步。

历史来源：此次从 Git 中各版本最后一次修改更新页的提交恢复说明，记录日期采用该提交日期。这些日期表示记录时间；版本号空缺保持空缺。原有独立发布文档保留其验证、安装和发布依据，作为历史资料，后续面向用户的更新内容统一维护在 JSON 中。
