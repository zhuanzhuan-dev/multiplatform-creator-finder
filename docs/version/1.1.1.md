# V1.1.1

## 更新内容

- 悬浮入口按抖音、快手、飞瓜逐行显示任务状态和进度，推荐流使用条数，飞瓜使用页数。运行、启动、暂停中的任务保留，空闲和结束任务隐藏。

- 修复跨平台设置锁定、草稿串用、异步保存覆盖及悬浮入口漏监听快手状态的问题。今日已刷保留全平台汇总和现有筛选。
