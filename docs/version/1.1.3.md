# V1.1.3

改善抖音推荐流类型判断，统一中文错误提示，并补全筛选结果中的当前值和实际生效阈值。

- 抖音推荐卡片默认按视频处理，减少缺少播放器标记或原生时长导致的类型未确认跳过。明确识别的直播、图文和广告继续按原规则处理。
- 网络、超时、授权、存储及插件连接等错误提供中文说明和操作建议；保留 HTTP 状态码、错误码及原始诊断记录。
- 达人作品列表加载失败时，提示检查网络连接；如使用代理，可尝试关闭或切换线路，刷新页面后重试。
- 点赞、视频时长、粉丝上下限的筛选提示同时显示当前值和实际生效的设置值。
- 低粉新号例外说明开关状态、作品列表完整性、作品数及平均点赞数的具体条件；通过时也展示对应阈值。
- 粉丝量读取失败单独标记为资料未读全，避免误报为超出设置范围。

- 更新说明改为配置驱动，恢复 Git 中可核实的 15 个旧版本说明，历史版本可展开查看。统一更新记录由配置生成。

验证：250 项测试、类型检查、构建及 dist 校验通过。对方电脑的实际采集效果仍需本地验证。

升级：重新加载插件并刷新采集网页后，手动继续任务。历史筛选记录保留当时的结果，新阈值提示用于后续采集。飞瓜上传维持现有设置。
