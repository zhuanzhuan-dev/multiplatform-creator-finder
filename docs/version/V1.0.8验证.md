# V1.0.8 侧栏与设置修复

发布日期：2026-09-06。适用目录：`multiplatform-creator-finder`。

## 使用变化

1. 在任意标签页点击工具栏图标即可打开助手。点击“开始本轮”时，使用当前抖音推荐页，或选择同窗口已有的推荐页；没有推荐页时创建一个。侧栏显示本轮绑定任务的状态，切换标签页后仍可暂停或停止。
2. 顶部增加“打开工作台”按钮，地址复用项目现有的工作台配置，与配对操作分别提供入口。
3. 运行设置每次编辑后自动保存。状态更新不会覆盖正在编辑的内容；关闭侧栏或重启 Chrome 后可恢复。临时不满足校验规则的设置保存为草稿，任务继续使用最后一次有效配置，修正草稿后再应用。高级筛选规则沿用“保存高级规则”操作。
4. 新配置默认使用 10–30 秒、中心 20 秒的随机预设。已有保存的模式和数值继续保留，点击“应用随机预设”可切换。

## 修复依据

此前仅为抖音推荐标签启用侧栏，从其他标签点击时先异步创建或选择推荐页，再调用打开侧栏。现在使用 Chrome 的全局侧栏与工具栏点击行为直接打开，并修复升级前遗留的标签级启用配置。首次打开按 [Chrome 官方侧栏接口](https://developer.chrome.com/docs/extensions/reference/api/sidePanel) 实现。

设置原本由每次状态快照重新初始化，编辑中的内容会被覆盖。现在界面仅在初次载入时恢复设置，后台按顺序处理保存请求，将有效设置与未完成草稿分别存入 `chrome.storage.local`。有效配置写入完成后再更新内存状态，避免旧响应覆盖新编辑。

旧随机区间使用连续三角分布；三个输入值是分布参数。当前改为截断正态分布：Box–Muller 采样，中心沿用 `typicalSeconds` 字段，标准差为 `(最长 - 最短) / 6`，超出范围重新采样，结果保留一位小数。上下限相同时返回该值。默认配置的多数样本靠近 20 秒。

随机节奏用于调整等待时间，无法保证避免平台风控。平台登录、验证和其他异常仍需按实际页面状态处理。

## 验证

- `pnpm package`：60 项测试、类型检查、构建、发布文件检查通过。
- 20,000 次确定性采样测试：校验上下界、均值、标准差、中心区间比例，并确认存在超过 100 个不同结果。
- 后台测试：设置连续写入、进程重启恢复、无效草稿隔离、升级旧标签配置、从普通标签创建并绑定推荐页通过。
- 真实 Chrome for Testing 151.0.7922.34：使用独立配置，首次工具栏点击、默认预设、自动保存、状态更新保留编辑、关闭重开、无效草稿恢复、工作台按钮以及完整浏览器重启后的设置保留通过。
- 后台浏览器回归：从其他标签页启动后复用推荐页，暂停取消、连续刷新、调试连接重连、页面解冻、后台进程重启及到时停止通过；本次到时停止延迟 2 毫秒。该回归使用本地推荐页样本，完整切换间隔最长 6.034 秒；本轮没有重复此前的 30 分钟长测。
- 发布 ZIP：逐个比较全部 20 个文件与 `dist` 的内容，确认清单、包版本及侧栏入口一致。

侧栏测试通过 CDP 的真实工具栏动作打开扩展，直接运行发布构建和 Chrome 存储接口。没有模拟扩展 API，也没有配对账号或上传采集数据。

复现侧栏测试：

```sh
CHROME_BIN='/path/to/Google Chrome for Testing' node scripts/test-panel-browser.mjs
```

再次执行时，可将首轮报告中的独立配置路径传入 `RESUME_PROFILE`，验证 Chrome 重新启动后的持久化状态。
