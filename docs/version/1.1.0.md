# V1.1.0

多平台任务支持抖音推荐与飞瓜视频库独立运行，通过顶部平台任务浮窗切换，默认跟随当前标签页。

- 飞瓜点击「继续采集」时在后台恢复已有标签页；原标签页关闭时后台新建，保留用户当前页面。单独点击「打开飞瓜视频库」仍切到前台。
- 飞瓜统计使用紧凑的轻边框分组，标签和值紧邻，兼顾空间与可读性。
- 飞瓜默认每批采集 50 页，每页随机等待 4–6 秒，支持设置。达到批次上限暂停并建议休息至少 3 小时，用户可知晓风险后提前继续。
- 本轮候选按飞瓜页面筛选、规避词和账号去重保留；后续采集命中规避词时移除整个账号。最近处理记录按平台展示近 24 小时事件。
- 延续 V1.0.27 的浏览采集、完整观察存储与 24 小时清理机制。

验证：`pnpm check` 的 212 项测试、类型检查、构建与 dist 校验通过；后台恢复包含复用、导航恢复和后台新建标签页的自动化测试。真实网页后台运行仍待验收。

已知问题：仅一页且没有分页控件的筛选结果可能被识别为分页异常并暂停；本版本尚未修复。截图中的本地观察存储已满提示仍需结合实际安装版本和存储状态排查。

升级后重新加载扩展并刷新采集网页，再手动继续任务。已有候选、队列和配对设置继续使用原存储。本次更新本地扩展，不部署服务端。
